# Чеклист защиты лабораторной №2

- [ ] ПК + телефон Аврора находятся в одной локальной сети.
- [ ] На ПК запущен FastAPI по HTTPS на `0.0.0.0:8443`; IP ПК записан.
- [ ] Самоподписанный сертификат выпущен с SAN `IP:<IP ПК>`, показан SHA-256 fingerprint.
- [ ] На ПК открыта страница `https://<IP ПК>:8443/` и `/docs` (или `/openapi.json`).
- [ ] После входа демонстрируются POST 201, GET 200, PUT 200, DELETE 204.
- [ ] GET с ETag демонстрирует HTTP 304; показаны Last-Modified и Cache-Control.
- [ ] Показаны 400, 401, 403, 404, 500 (500: только demo-mode).
- [ ] Та же HTML-страница открывается на телефоне в браузере и выполняет CRUD.
- [ ] Нативное приложение собрано под ARM, подписано и установлено на физический телефон.
- [ ] На нативном экране выставлен URL HTTPS и fingerprint, есть авторизация JWT.
- [ ] Через нативный клиент выполнен полный CRUD-цикл.
- [ ] Offline: выключена сеть, список по-прежнему виден благодаря SQLite.
- [ ] Offline: создание, изменение, удаление сохраняются в очереди.
- [ ] Online: после восстановления сети очередь отправлена, статусы изменились на «синхронизировано».
- [ ] Изменения видны в браузере ПК после обновления.
- [ ] Сняты скриншоты сетевой ошибки и ошибок 4xx/5xx.

**Не утверждать, что приложение проверено на физическом телефоне, пока не проведены реальные тесты.**
